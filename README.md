# Admin-lte1

## 👉 FILE UTAMA: [`adminlte/dist/adminlte.php`](adminlte/dist/adminlte.php)  

> Lokasi di laptop: `C:\xampp\htdocs\web\adminlte\dist\adminlte.php`  
> Lokasi di repo ini: `adminlte/dist/adminlte.php`   

Halaman **Rekap Nilai Mahasiswa** dari tabel `nilaimhsw` (database `db5d`), dengan fitur:

- pencarian berdasarkan nama
- filter predikat
- urut nilai akhir (naik/turun)
- pagination

## Cara menjalankan

1. Jalankan **Apache** dan **MySQL** di XAMPP.
2. Buka `http://localhost/web/adminlte/dist/adminlte.php` di browser.

File lain di repo ini (`bacadata.php`, `buat_tabel.php`, dan sebagainya) adalah file latihan pendukung.
